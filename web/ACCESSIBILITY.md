# Accessibility checklist

- The obstruction list is a text alternative to the map and is available by keyboard.
- Map markers have an accessible name containing their kind and title; the selected item is also shown in the detail region.
- All interactive controls use at least 44px minimum height.
- Focus styles use a visible, non-colour-only outline and the page remains usable at 200% zoom.
- Kind identity uses an icon, a repeating pattern and text label; colour is not the only signal.
- Light and dark tokens use high-contrast ink/surface pairs, with dark-mode support from the system preference.
- Reduced-motion preferences disable the loading animation and smooth scrolling.

Run an axe scan and complete keyboard/screen-reader checks before release.
